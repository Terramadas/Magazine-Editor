Magazine Editor help v0.3.1

Start

Set the magazine name, issue, date and page size on the left. Add pages (Blank, Cover, Backside, Article, Index), then add blocks and drag them into place. Everything is saved automatically in your browser; use Save JSON for a real backup file.

Pages

Duplicate, delete, move Up/Down, give a page a label, switch the page number on or off and pick a background colour. A cover image can be dragged and zoomed to fill the page. View: 1 page or 2-page spread, zoom 40 to 160%.

Blocks

Text, Title, Image, Table, Shape, Index and Rotated text. Drag to move, use the corner handle to resize. Blocks snap to the grid (size in mm in the settings). The red line shows the bleed edge. The Layers list sets the order, top is front. The right panel (Inspector) shows the selected block.

Text

Open a text block to edit it: bold, italic, underline, strike, lists, alignment and 15 font choices. Fonts come from your system and are not embedded.

Index

Tick "Index title" on a text block, add an Index block and press "Rebuild index". EPUB links to those pages, PDF prints the page numbers.

Save and open

Save JSON writes one .mag.json file with all text and images. Open reads it back.

Export

PDF and EPUB export the whole magazine. PNG exports the page you have selected as an image, for example for a web gallery: choose A6, A5, A4, A3, US Letter, the magazine page size or a custom pixel width, and 72, 150, 300 or 600 dpi. A4 at 300 dpi is 2480 x 3508 px. The height follows the magazine page shape. The PNG has no grid and no bleed line. PNG and PDF draw text the way the editor shows it (alignment, size, bold, italic, underline, strike, lists). Fonts must be installed on the computer you export from.

Very large combinations (such as A3 at 600 dpi) can be refused by the browser. Use 300 dpi instead.
